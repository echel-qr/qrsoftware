# Echel Print

Current Echel website/backend and English desktop Agent sources.
Node.js 22. Run `npm ci`, `npm test`, and `npm run check` for local development.
Production: `npm ci --omit=dev`, then `npm start`.
Render health check: `/healthz`. Configure a fresh Echel database and private environment variables.
The complete deployment guide is delivered with the outer release archive.
Manipuri translation remains incomplete; real cloud/payment/printing acceptance is pending.
